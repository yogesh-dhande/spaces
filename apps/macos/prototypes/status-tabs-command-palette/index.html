UI decision mockup · August 2026

Command palette context, operational sidebar color, and draggable tabs

Each direction uses the same information and interactions. Click a direction below, then drag the terminal tabs to test the reorder cue. The command palette shows both terminal-label cases: a reported terminal title takes priority; a foreground command is used only when no title is available.

Baseline

Current — small glyphs carry most state

Workspace headers report lifecycle only. Runtime state appears on a small icon. Tabs select and rename, but do not reorder.

Observed issue: the footer promises ⌘X, while matching currently requires the configured leader + X (⌘⌥X by default). A terminal without an OSC title has no foreground-command fallback in the palette.

Direction A

Text tint — fastest scan, smallest layout change

Color the target name and kind glyph. The workspace name adopts the highest-attention child color, while selection keeps its neutral fill and teal rail.

Tradeoff: strongest scanability and closest to the request, but several colored labels can feel lively in a busy workspace. Recommended starting point.

Direction B

Status rail — quiet text, clear hierarchy

Keep labels neutral and add a narrow semantic rail to each target and workspace header. Status stays visible without recoloring typography.

Tradeoff: calm and dense, but the workspace rail competes with the existing teal selection rail and needs careful indentation to avoid ambiguity.

Direction C

Row wash — attention reads as a region

Apply a low-alpha semantic surface behind each status-bearing row. Workspace headers use the strongest descendant state as a subtle outlined wash.

Tradeoff: easiest to notice peripherally and works well for workspace headers, but repeated fills make the sidebar visually heavier.

Direction D

Status chips — explicit and accessible

Use compact semantic words at the trailing edge: working, blocked, done, stopped, running, and exited. Workspace chips show the highest-attention state.

Tradeoff: removes all interpretation and never relies on color alone, but adds the most visual and horizontal weight to a compact sidebar.

Drag behavior shown
Dragging moves a tab within its current strip, shows a brand-teal insertion marker, and persists the resulting array order. It does not imply drag-out or cross-window movement.
Palette priority shown
stable session name · reported OSC title; if absent, stable session name · foreground display command. Workspace and branch remain on the lower line.
